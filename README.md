## ダンジョンの構成

1つのダンジョンは4フロアです。フロア1〜3は手下が3体ずつ、フロア4は手下2体のあとにボスが出ます（数は `FLOOR_N` `MINION_HITS` `BOSS_HITS` で変えられます）。

- フロア1〜3：はじめて入ったときだけ、そのフロアの「ものがたり」が自動で流れ、そのあとのバトルでものがたりの問題が出ます。まちがえずに倒すと 💎100（1回だけ）。
- フロア4：はじめてのときは「総まとめ」（図と要点）を見せてからボス戦。ボスは全フロアの問題から出題します。
- ものがたりと総まとめは、ダンジョン入口からいつでも読み直せます。

## ものがたりの書き方

`JIN_STORY` に、ダンジョン番号ごとにフロア1〜3の3つを書きます。1つは `{t:題, f:図, l:[[話し手, セリフ, 光らせる部分]], q:[問題]}` です。

- 話し手：`s`（しずく）`n`（ネフ先輩）`m`（ミクロ）`boss` など
- 図：`neph` `clr` `cell` `glom` `jga` `prox` `loop` `prin` `fluid` `raa` `kdist`
- 光らせる部分：図のパーツ名を空白区切りで（例 `"desc thin"`）
- 問題：`{q:問題, a:正解の番号, o:[[選択肢, 解説], …]}`。そのフロアのバトルで出ます
- 総まとめと機序カードは `JIN_CARD` に `{t, f, hl, sum:[3行]}` で書きます
