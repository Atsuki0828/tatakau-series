- 💊 **たたかう薬理学**：薬理学の講義（17ダンジョン）

**遊ぶ：** https://atsuki0828.github.io/tatakau-series/

1ファイル（`index.html`）だけで動きます。進み具合はブラウザに保存されます。

## ものがたりの書き方

`JIN_STORY` に、ダンジョン番号ごとに3幕を書きます。1幕は `{t:題, f:図, l:[[話し手, セリフ, 光らせる部分]], q:[理解チェック]}` です。

- 話し手：`s`（しずく）`n`（ネフ先輩）`m`（ミクロ）`boss`
- 図：`neph`（ネフロン）`clr`（ろ過・再吸収・分泌）`cell`（上皮細胞の輸送）
- 光らせる部分：図のパーツ名を空白区切りで（例 `"desc thin"`）
- 理解チェック：`{q:問題, a:正解の番号, o:[[選択肢, 解説], …]}`
- 機序カードは `JIN_CARD` に `{t, f, hl, sum:[3行]}` で書きます
