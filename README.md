- 💊 **たたかう薬理学**：薬理学の講義（17ダンジョン）
- 🛡️ **たたかう免疫学**：免疫学の講義（17ダンジョン）
- 🦠 **たたかうウイルス学**：ウイルス学の講義（14ダンジョン）
- 🧫 **たたかう細菌学**：細菌学の講義（19ダンジョン）

## コイン・ショップ・見た目

- ガチャは廃止。バトルの **スコア** の 1/10 が コイン（🪙）になる。スコアは 正解（早いほど高い）・コンボ・弱点じゅもん・撃破・クリア・ノーミスで増え、ミス・逆効果・被ダメージで減る。
- 正解時のダメージは **答えたときに残っていたゲージ（0〜100%）** で、ぶきの「lo〜hi」の間で決まる（例：ピペット 30〜40 は安定、チャクラム 0〜80 は即答向き）。
- ショップ：ぶき9・いしょう8・おとも7。いしょう・おともは見た目だけ。価格は 4,000〜150,000。
- 画像素材は `assets/` に置くと自動で絵文字と差し替わる（なければ絵文字のまま）。
  - `assets/bg/<ゲームkey>.png`（背景）
  - `assets/player/<いしょうid>/idle.png・attack.png・cast.png`（自分。左下）
  - `assets/pet/<おともid>.png`
  - `assets/fx/<ぶきid>.png`（こうげきエフェクト）・`fx/hit.png`・`fx/spell.png`・`fx/enemy_hit.png`
  - `assets/mon/<ゲームkey>/<ダンジョン番号>-<まもの番号>.png`（てき。右上奥。3がボス）

## 勉強モード（試作）

- **講義ノート**：フロアごとに、講義資料の順にまとめたノート（出典ページと資料へのリンクつき）。データは `GM.NOTE[ダンジョン][フロア]={t,src,url,sec:[[見出し,[項目],ページ]]}`。いまは医動物学の総論（ダンジョン1〜3）だけ。
- **講義問題**：講義の小テストや Minimum Requirements を記述式で出題し、模範解答を見て ◎△× で自己採点する。データは `GM.LQ[ダンジョン]=[{f:フロア,src,q,a:[模範解答]}]`。いまは医動物学のダンジョン1〜7。
- はじめて入るフロアは「講義ノート → 講義問題 → ものがたり → バトル」の順に進む。
- **きょうの復習**（全教科）：バトルでまちがえた問題と、講義問題で △× にしたものを、1・3・7・14・30日後に出し直す（`st.srs`）。

## ダンジョンの構成

ダンジョン入口に4つのフロアが並び、フロアごとに「📜 読む」「⚔ はいる」があります。フロア1〜3は手下3体ずつ、フロア4は手下2体のあとにボスです（数は `FLOOR_N` `MINION_HITS` `BOSS_HITS` で変えられます）。

- 「はいる」を押すと、まだ読んでいないフロアは先に内容が流れ、そのあとそのフロアだけのバトルになります。
- フロア1〜3のバトルでは、そのフロアまでの ものがたり（第1幕〜その幕）で説明した内容だけが出ます。問題と手下は、文章の重なりから自動で幕に割り当てています（`actTags`、しきい値 `ACT_TH`）。フロア4はダンジョン全体から出ます。
- フロア1〜3のバトルでは、そのフロアのものがたりの問題も出ます。まちがえずに倒すと 💎100（1回だけ）。フロアの初クリアで 💎50。
- フロア4は「総まとめ」（図と要点）→手下→ボス。ボスは全フロアの問題から出題し、倒すとダンジョンクリア（💎300、ノーミスで+200、機序カード）。
- 読むのはいつでも。バトルは、前のフロアをクリアすると入れます。

## ものがたりの書き方

`JIN_STORY` に、ダンジョン番号ごとにフロア1〜3の3つを書きます。1つは `{t:題, f:図, l:[[話し手, セリフ, 光らせる部分]], q:[問題]}` です。

- 話し手：`s`（しずく）`n`（ネフ先輩）`m`（ミクロ）`boss` など
- 図：`neph` `clr` `cell` `glom` `jga` `prox` `loop` `prin` `fluid` `raa` `kdist`
- 光らせる部分：図のパーツ名を空白区切りで（例 `"desc thin"`）
- 問題：`{q:問題, a:正解の番号, o:[[選択肢, 解説], …]}`。そのフロアのバトルで出ます
- 総まとめと機序カードは `JIN_CARD` に `{t, f, hl, sum:[3行]}` で書きます
